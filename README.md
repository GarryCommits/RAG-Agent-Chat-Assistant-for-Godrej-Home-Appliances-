# RAG-Agent-Chat-Assistant-for-Godrej-Home-Appliances-
Godrej Smart Appliances RAG Chatbot is a local CLI chatbot built with LangChain, Ollama, and ChromaDB. It answers questions about Godrej home appliances by retrieving relevant customer reviews from a local dataset and using the Llama 3.2 language model with mxbai-embed-large embeddings for efficient semantic search.
